# 3.2 Suspicious Outbound Traffic Report

## 1. Executive Summary
This report details the findings of the network traffic analysis conducted on the firewall and netflow logs. We have identified several internal hosts exhibiting suspicious outbound connection patterns, including high-volume data transfers and connections to potentially malicious external IP addresses.

## 2. Methodology
The analysis focused on identifying outbound connections from internal networks to external IP addresses. The following criteria were used to flag suspicious activity:
- **High Connection Frequency**: Source-destination pairs with connection counts in the top 1 percentile.
- **Large Data Transfers**: Sessions with byte transfers in the top 1 percentile.
- **Non-Standard Port Usage**: Frequent outbound connections on ports commonly used for administrative or lateral movement (e.g., 22, 445, 3389).
- **Internal vs. External Mapping**: Filtering out RFC1918 internal traffic to focus on exfiltration risks.

## 5. Key Observations
1. **RDP/SMB Exposure**: Significant outbound traffic on Port 3389 (RDP) and Port 445 (SMB) to external IPs (e.g., `142.250.74.14`, `103.25.56.10`) suggests potential data exfiltration or unauthorized remote access.
2. **SSH to Unknown External IP**: Host `10.0.0.20` established a high-volume SSH session to `188.166.10.4`.
3. **Consistent Data Exfiltration**: Multiple hosts show a total outbound volume exceeding 500MB, which is unusually high for standard user workstations and warrants further investigation into the nature of the data being transferred.

## 6. Recommendations
- **Immediate Action**: Block outbound traffic on ports 445 and 3389 at the perimeter firewall for all internal workstations.
- **Investigation**: Review logs for user activities on hosts `10.0.0.10` and `10.0.0.20` during the identified timeframes.
- **EDR Review**: Check endpoint logs for the identified hosts to see which processes initiated these outbound connections.
